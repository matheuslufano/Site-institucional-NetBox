# Pôsteres do carrossel

Imagens promocionais dos filmes, com os direitos pertencentes aos respectivos estúdios/distribuidores. Arquivos WebP locais, com até 480 × 720 px, proporção original preservada. O cadastro content/blog/spotlights.json relaciona cada arquivo à fonte e ao trailer. Os fundos continuam usando as imagens já enviadas ao Blog. Não houve geração artificial de cartazes.

Fontes consultadas em 30/10/2026. Sony, Universal, Disney/Pixar, 20th Century Studios, Focus Features e A24 fornecem os materiais de seus próprios sites; os pôsteres de Michael e Devoradores de Estrelas vieram do arquivo promocional IMP Awards. Trailers conferidos nos canais oficiais dos estúdios, com resposta HTTP 200 e título/canal verificados quando disponíveis via oEmbed.
